# Foundation Library：按需补习，不是主线前置课

这里保留旧教材 Day 1–18 的完整内容。迁移只调整目录、导入和输出路径，没有重写或扩写课程。多数学习者只需走对应模块的 60–180 分钟快速路径；需要深入时再完成原章全部练习。

| 路由 | 主题 | 何时调用 |
|---|---|---|
| [F01](f01_terminal_python/README.md) | 终端 / Python | Day 0 任务 1 失败 |
| [F02](f02_csv_json/README.md) | CSV / JSON | registry 或 manifest 处理失败 |
| [F03](f03_modules_testing/README.md) | 函数、模块、测试 | 调用链或检查器阻塞 |
| [F04](f04_git/README.md) | Git | 无法提交、比较、恢复 |
| [F05](f05_linux_processes/README.md) | Linux / 进程 | 环境、进程、退出码阻塞 |
| [F06](f06_environments_dependencies/README.md) | 环境与依赖 | 安装、import、venv 阻塞 |
| [F07](f07_numpy_observations/README.md) | NumPy / observation | shape、dtype、图像或 state 阻塞 |
| [F08](f08_episode_evaluator/README.md) | mini evaluator | episode、step、success 阻塞 |
| [F09](f09_tensors/README.md) | Tensor | shape、dtype、device 阻塞 |
