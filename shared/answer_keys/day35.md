# Day 35 / Gate 5 参考答案（挑战后再看）

1. conversion rate 的分母是进入前一阶段的 episode；总体成功率无法指出损失发生在哪个转换。
2. pair asymmetry 只纳入两臂都有效且完成的 pair；缺臂不能当失败补齐。
3. oracle net effect 在本课是 recovery rate 减 damage rate；仍需同时展示两个原始分子/分母。
4. 最大漏斗下降与某 oracle 恢复同时出现只形成候选解释，不能排除控制、阈值、文本/像素显著性等 alternative。
5. 当净效应差、样本量或匹配证据达不到预登记规则时，应选择 insufficient evidence，并用新 matched 输入做 falsifier。
