# Day 43 参考答案

1. **pilot 要回答什么？** 回答短训练链路是否能产生可解释的训练/验证日志、按冻结规则停止，并从完整状态恢复；不能回答正式性能或泛化。
2. **为什么不能只保存模型权重？** 恢复还需要 optimizer state、step、早停最佳值与计数、配置和数据身份；缺任一项都可能改变后续轨迹。
3. **patience 与 `min_delta` 各控制什么？** `min_delta` 定义“足够大的改善”，patience 允许连续多少次未达该改善才停止。
4. **如何证明 resume 不是重新训练？** 记录恢复起点，并让中断恢复轨迹与同 seed、同输入、同配置的未中断基线在最终 step、日志和模型 hash 上一致。
5. **CPU toy 通过后可以声称什么？** 只能声称教学脚本的日志/早停/checkpoint/resume 闭环成立；不能声称 SmolVLA、GPU 或正式训练已成功。
